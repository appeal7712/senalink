# 컨텐츠 시즌 일정 · 카드 카피 (정본)

> **이 파일이 정본이다.** 스케줄/문구를 바꿀 때 여기부터 고치고, 그다음 코드를 맞춘다.  
> 시각은 전부 **KST (Asia/Seoul)**. Firestore 없음.  
> 코드: `src/config/contentSeasonAnchors.js` → `src/lib/contentSeasonSchedule.js` → `src/components/ContentSeasonBadges.jsx`

---

## 0.1 테두리 스핀 vs 회색 고정 (최종)

**원칙: 진짜 “전투/시즌 진행”일 때만 테두리가 돈다.** 나머지는 전부 회색 고정.

| 컨텐츠 | `burning` / 스핀 | 회색 고정 (`is-prep`) |
|--------|------------------|----------------------|
| **길드전** | `frontStatus === '길드전 진행 중'` | 방어덱 설정·배치·길드 매칭·정산 중·시즌 준비·시즌 사이 1주 쉼 |
| **총력전** | `frontStatus === '전투 진행'` | 라운드 준비·라운드 결산·시즌 준비·화 마감~다음 목 휴식 |
| **상급 결투장** | `시즌 진행 중` | `시즌 준비` |
| **강림 원정대** | `시즌 진행 중` | `시즌 준비` (월 02:00~09:00 교대 포함) |

코드: `burning` → UI `is-live`(스핀) / `false` → `is-prep`(회색 고정).  
앞면 멘트(`frontStatus`)와 테두리는 위 표로만 연결한다.

## 0. 카드 UI (먼저 읽을 것)

플립 카드 4장. 순서 고정:

1. 길드전  
2. 상급 결투장  
3. 총력전  
4. 강림 원정대  

| 면 | 보여주는 것 | 필드 |
|----|-------------|------|
| **앞** | 아이콘 + **지금 이 시간**의 상태 한 줄 | `frontStatus` |
| **뒤 (호버)** | 컨텐츠 이름 + 시즌 종료일 + 게이지바 | `name` · `endsAtLabel` · `progress` |

앞면은 “시즌 이름”이 아니라 **현재 페이즈 멘트**다.  
뒷면은 **이름 + 종료일 + 게이지**만. (게이지 안에 D-day 텍스트 넣지 않음)

## 1. 라이브 앵커 (2026-08-25 확인)

`CONTENT_SEASON_ANCHORS` 값과 동일해야 한다.

| id | 앵커 필드 | 이번 시즌 시작 | 이번 시즌 종료 | 다음 시즌 |
|----|-----------|----------------|----------------|-----------|
| 상급결투장 | `advancedArenaThursday` | **2026-08-20** (목) | **2026-09-03** (목) 02:00 | +14일 주기 |
| 총력전 | `totalWarThursday` | **2026-08-20** (목) | **2026-09-01** (화) 09:00 | 이틀 쉼 후 **09-03**(목) 패치 오픈 |
| 길드전 | `guildWarThursday` | **2026-08-06** (목) | **2026-09-17** (목) 00:00 기준 6주 끝 | **1주 쉼** → **09-24**(목) 개막 |
| 강림원정대 | `expeditionMonday` | **2026-08-24** (월) 09:00 | **2026-09-07** (월) 02:00 | 같은 날 **09:00** 재시작 |

원정대 = **14일** (월 09:00 ~ 다다음? 다음다음이 아니라 **+14일 월 02:00**).

## 2. 길드전 (제일 헷갈림 — 예시 필수)

### 2.1 큰 그림

- 시즌 길이: **6주 / 18라운드**. 개막·매주 휴전 = **목요일**.  
- 시즌 끝나면 **7일 휴식** → 다음 목요일 다시 개막.  
- 주중은 **이틀 주기**: 방어일 ↔ 경기일 교대.

| 요일 | 역할 |
|------|------|
| **목** | 휴전 (시즌 준비). 단, **수 본게임 연장으로 목 00:00~02:00만 전투** |
| **금 · 일 · 화** | **방어 준비일** |
| **토 · 월 · 수** | **경기 진행일** |

### 2.2 방어 준비일 (금 / 일 / 화) — 시각표

| 시각 (KST) | 앞면 `frontStatus` |
|------------|-------------------|
| 00:00 ~ 02:00 | ⚠️ **전날 본게임 연장** → `길드전 진행 중` (아래 2.4) |
| 02:00 ~ 09:00 | `정산 중` (전투 종료 후 ~ 방어덱 설정 전) |
| 09:00 ~ 20:00 | `방어덱 설정` |
| 20:00 ~ **다음날 08:00** | `방어덱 배치` |

### 2.3 경기 진행일 (토 / 월 / 수) — 시각표

| 시각 (KST) | 앞면 `frontStatus` |
|------------|-------------------|
| 00:00 ~ 08:00 | `방어덱 배치` (전날 방어 배치 연장) |
| 08:00 ~ 09:00 | `길드 매칭` |
| 09:00 ~ **다음날 02:00** | `길드전 진행 중` |

### 2.4 본게임이 “다음날 새벽 2시”까지인 이유 (절대 헷갈리지 말 것)

규칙 원문:

> 경기 진행일(월/수/토) **09:00 ~ 익일 02:00** 본게임 진행

즉 **달력 요일이 바뀌어도 02:00 전까지는 전투**다.

| 본게임 시작 | 본게임 종료 | 종료 직후 요일에 보이는 것 |
|-------------|-------------|---------------------------|
| **월** 09:00 | **화** 02:00 | 화 02시 이후 → 방어일 스케줄 |
| **수** 09:00 | **목** 02:00 | 목 02시 이후 → 휴전(`시즌 준비`) |
| **토** 09:00 | **일** 02:00 | 일 02시 이후 → 방어일 스케줄 |

### 2.5 같은 “화요일”이라도 시각에 따라 멘트가 다르다 (에이전트 함정)

| 언제 | 앞면 | 왜 |
|------|------|-----|
| **화요일 01:00** | `길드전 진행 중` | 월요일 본게임이 아직 안 끝남 (~02:00) |
| **화요일 03:00** | `정산 중` | 전투 끝, 방어 설정 전 |
| **화요일 12:00** | `방어덱 설정` | 화요일이 방어 준비일, 09~20 |
| **화요일 21:00** | `방어덱 배치` | 20:00부터 배치 |

❌ 잘못: “화요일이니까 무조건 방어덱 설정”  
✅ 올바름: **먼저 00~02 연장 전투인지 보고**, 그다음 방어일 표를 본다.

### 2.6 라운드 번호

- 시즌 개막 목요일 이후, **토·월·수**마다 그날 **08:00**이 지나면 라운드 +1.  
- 상한 18.  
- 예: 시즌 시작 2026-08-06(목) → … → 2026-08-24(월) 08:00 이후 = **R8**.  
- 방어일(화)에도 표시용 라운드는 **직전 경기일까지 쌓인 번호**를 유지.

### 2.7 뒷면 종료일

- `endsAtLabel` = 시즌 시작 + **42일** 날짜 + ` 종료`  
- 예: 2026-08-06 시작 → **2026.09.17 종료**  
- 휴식 주(09-17 ~ 09-24)에는 앞면 `시즌 준비`, 게이지 100%에 가깝게.

## 3. 총력전

### 3.1 시즌 구간

| 단계 | 시각 |
|------|------|
| 입장 오픈 | 앵커 **목요일** 00:00~ |
| R1 개막 | 그다음 **금요일 14:00** |
| 시즌 마감 | 앵커 기준 **+12일 화요일 09:00** (22라운드 마지막 구간 포함) |
| 다음 시즌 | 마감 후 약 이틀 쉼 → 다음 **목요일** 패치 오픈 |

예 (앵커 2026-08-20):

- R1: **08-21 금 14:00**  
- 종료: **09-01 화 09:00**  
- 다음 오픈: **09-03 목**

### 3.2 앞면 — 시즌 **진행 중일 때만** 데일리 슬롯

| 시각 (KST) | 슬롯 의미 | 앞면 멘트 |
|------------|-----------|-----------|
| 09:00 ~ 17:00 | 세팅1 + 세팅~전투 공백 | `라운드 준비` |
| 17:00 ~ 20:00 | 전투1 | `전투 진행` |
| 20:00 ~ 21:00 | 결산1 | `라운드 결산` |
| 21:00 ~ 05:00 | 세팅2 + 공백 | `라운드 준비` |
| 05:00 ~ 08:00 | 전투2 | `전투 진행` |
| 08:00 ~ 09:00 | 결산2 | `라운드 결산` |

시즌 밖(금 14:00 전, 화 09:00 후 ~ 다음 시즌): `시즌 준비`

### 3.3 예시

| 언제 | 앞면 |
|------|------|
| 2026-08-25 **12:56** (시즌 중) | `라운드 준비` |
| 2026-08-25 **18:00** | `전투 진행` |
| 2026-08-25 **20:30** | `라운드 결산` |

뒷면 종료일 예: `2026.09.01 종료`

## 4. 상급 결투장

| 항목 | 규칙 |
|------|------|
| 주기 | 약 2주 (앵커 목 +14일) |
| 마감 | **수→목 새벽 02:00** = 종료일 목 **02:00** |
| 앞면 (진행 중) | `시즌 진행 중` |
| 앞면 (종료 후) | `시즌 준비` |

예: 2026-08-20 시작 → 뒷면 `2026.09.03 종료`

시간대별 세팅/전투 세분은 **없음**. 앞면은 위 두 멘트만.

## 5. 강림 원정대

| 항목 | 규칙 |
|------|------|
| 주기 | **2주** |
| 재시작 | 월요일 **09:00** |
| 마감 | **+14일** 월요일 **02:00** |
| 앞면 (09:00~마감) | `시즌 진행 중` |
| 앞면 (월 02:00~09:00 공백) | `시즌 준비` |

예: 앵커 2026-08-24 → 09:00 오픈 → **2026-09-07 02:00** 마감 → 09-07 09:00 다음 시즌.

❌ `9월 24일 ~ 9월 31일` 같은 표기는 쓰지 말 것 (9월 31일 없음, 9/24는 목요일 = 길드전 다음 개막일과 혼동).

## 6. 코드 구현 체크리스트 (다른 에이전트용)

1. 앵커 날짜가 §1 표와 같은지 확인.  
2. 길드전: **반드시** `hour < 2` 이고 요일이 일/화/목이면 `길드전 진행 중`을 **방어일 표보다 먼저** 판정.  
3. 길드전 주기 `cycleStartMs(..., 49)` · 시즌 종료 `+42일`.  
4. 총력전 앞면 슬롯은 **burning일 때만**.  
5. 뒷면은 `endsAtLabel` (`YYYY.MM.DD 종료`) + 게이지 width만.  
6. UI 새로고침은 분 단위 권장 (매칭 08~09, 전투 마감 02:00).  
7. 이 문서를 안 읽고 “화요일 = 방어”만 단정하지 말 것.  
8. **테두리 스핀은 §0.1 표만** — 결산·배치·설정에서는 돌리지 말 것.

## 7. 한 줄 요약

- **앞면** = 지금 시각의 페이즈 멘트  
- **뒷면** = 이름 · 종료일 · 게이지  
- **길드전 화 새벽** = 아직 전투 / **길드전 화 낮** = 방어 설정  
- 날짜 의 = §1 라이브 앵커 표
