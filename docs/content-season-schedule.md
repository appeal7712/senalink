## 2. 길드전 (가장 중요)

### 2.1 큰 그림

- **6주 / 18라운드** 시즌 + 끝나면 **7일 쉼** → 다음 목 개막.  
- **목** = 휴전일 (새벽에 수 전투 연장·정산 후 **09:00**부터 휴전).  
- **금·일·화** = 방어 준비일 (금은 **09:00**부터 방어덱 설정으로 재개).  
- **토·월·수** = 경기 진행일.

### 2.2 수→목→금→토 타임라인 (외울 것)

```
수 09:00 ─── 길드전 진행 중 ───▶ 목 02:00
목 02:00 ─── 정산 ──────────▶ 목 09:00
목 09:00 ─── 휴전일 ───────────▶ 금 09:00   ← 금 08~09도 휴전일
금 09:00 ─── 방어덱 설정 ─────▶ 금 20:00
금 20:00 ─── 방어덱 배치 ─────▶ 토 08:00
토 08:00 ─── 상대 길드 매칭 ──▶ 토 09:00
토 09:00 ─── 길드전 진행 중 ──▶ (익일 02:00)
```

그 뒤 일·화는 일반 방어일: 전투 끝(02) → `정산`(~09) → `방어덱 설정` → `방어덱 배치` → (월/수) 매칭 → 전투.

### 2.3 절대 금지

| ❌ 하면 안 됨 | ✅ 올바른 것 |
|--------------|-------------|
| 목 02시부터 `휴전일` | 목 02~09 = **`정산`** |
| 금 오전을 `정산` | 금 ~09 = **`휴전일`**, 09~ = 방어덱 설정 |
| 월·수·토 08~09를 `정산` | **`상대 길드 매칭`** |
| 주중 공백을 `시즌 준비` | `시즌 준비` = **시즌 사이 1주 쉼만** |
| “화요일이니까 방어덱 설정” | 먼저 **00~02 연장 전투**인지 본다 |

### 2.4 판정 순서 (코드와 동일)

1. 일·화·목 **hour < 2** → `길드전 진행 중` (전날 본게임 연장)  
2. 목 **hour < 9** → `정산`  
3. 목 (나머지) → `휴전일`  
4. 토·월·수 → 배치(~08) / `상대 길드 매칭`(08~09) / `길드전 진행 중`(09~)  
5. 일·화 → `정산`(~09) / 설정(09~20) / 배치(20~)  
6. 금 → `휴전일`(~09) / 설정(09~20) / 배치(20~)  
7. 시즌 밖(42일 후 ~ 다음 49일 사이클) → `시즌 준비`

### 2.5 본게임은 익일 02:00까지

경기일(월/수/토) **09:00 ~ 익일 02:00**. 달력이 바뀌어도 02:00 전은 전투.

| 시작 | 종료 | 직후 |
|------|------|------|
| 월 09 | 화 02 | 화 02~09 `정산` → 09~ 방어 |
| 수 09 | 목 02 | 목 02~09 `정산` → 목 09~금 09 `휴전일` → 금 09~ 방어 → 토 매칭·전투 |
| 토 09 | 일 02 | 일 02~09 `정산` → 09~ 방어 |

### 2.6 예시

| 언제 | 앞면 |
|------|------|
| 화 01:00 | `길드전 진행 중` |
| 화 03:00 | `정산` |
| 월 08:30 | `상대 길드 매칭` |
| 목 03:00 | `정산` |
| 목 08:30 | `정산` |
| 목 10:00 | `휴전일` |
| 금 08:30 | `휴전일` |
| 금 10:00 | `방어덱 설정` |
| 토 08:30 | `상대 길드 매칭` |

### 2.7 라운드 · 뒷면

- 라운드: 개막 목 이후 **토·월·수**의 **08:00**이 지날 때마다 +1 (상한 18).  
- 뒷면 종료일: 시즌 시작 + **42일** · `YYYY.MM.DD 종료`.  
- 휴식 주: 앞면 `시즌 준비`, 게이지 ≈ 100%.  
- 주기 코드: `cycleStartMs(..., 49)`.

## 3. 총력전

### 3.1 시즌 구간

| 단계 | 시각 |
|------|------|
| 입장 오픈 | 앵커 **목** 00:00~ |
| 일일 싸이클 시작 | 그다음 **금 09:00** |
| R1 | 그다음 **금 14:00** |
| 마감 | 앵커 +**12일** **화 09:00** (R1~22) |
| 시즌 결산 | 마감 **화 09:00** ~ **수 09:00** |
| 시즌 준비 | **수 09:00** ~ 다음 시즌 **금 09:00** (다음 **목** 00:00 앵커 포함) |
| 다음 일일 싸이클 | 다음 시즌 **금 09:00**~ |

예 (앵커 2026-08-20): R1 = 08-21 금 14:00 · 종료 09-01 화 09:00 · 결산 09-01 화 09~09-02 수 09 · 준비 09-02 수 09~09-04 금 09 · 다음 싸이클 09-04 금 09:00~ (앵커 09-03 목).

**밍봉 확인 (2026-09-01):**  
- 목 00:00 ~ 금 09:00 = `시즌 준비` (입장 오픈 전용 멘트 없음).  
- 화 09:00 ~ 수 09:00 = `시즌 결산` · 수 09:00 ~ 금 09:00 = `시즌 준비`.  
- R1~22 = 금 14:00 기점 일자 카운트, 게임과 동일하게 유지.

### 3.2 시즌 중 데일리 슬롯 (**금 09:00** ~ **화 09:00** 전)

| 시각 | 앞면 |
|------|------|
| 09 ~ 17 | `라운드 준비` |
| 17 ~ 20 | `전투 진행 중` ← 스핀 |
| 20 ~ 21 | `라운드 결산` |
| 21 ~ 05 | `라운드 준비` |
| 05 ~ 08 | `전투 진행 중` ← 스핀 |
| 08 ~ 09 | `라운드 결산` |

화 **08~09** = 마지막 `라운드 결산` → **09:00** 정각부터 `시즌 결산`.

게이지: 금 14:00 → 화 09:00. 주기 `cycleStartMs(..., 14)`.
