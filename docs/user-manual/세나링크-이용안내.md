# 세나링크 이용 안내

세븐나이츠 유저를 위한 **길드 허브 · 공략 · 도감 · 도구** 사이트입니다.

- 주소: [https://senalink.kr](https://senalink.kr)

이 문서는 **웹사이트 코드와 별도**로 배포·공유하는 유저용 메뉴얼입니다.

---

## 1. 화면 구성 (상단 메뉴)

| 메뉴 | 하는 일 |
|------|---------|
| **메인** | 메타 덱·픽률·뉴스·입장 안내 |
| **길드 허브** | 길드원끼리 공략·길드전·공지 공유 (구글 로그인) |
| **공략 허브** | 누구나 보는 공용 공략·티어리스트 |
| **도구** | 승확 계산기, 티어리스트 메이커 등 |
| **도감** | 영웅·장비·펫·시스템 정보 |
| **마이프로필** | 닉네임·티어·아바타 설정 (우측 상단) |

첫 방문 시 **닉네임**을 정해야 대부분의 기능을 쓸 수 있습니다. 닉네임은 **마이프로필**에서만 바꿉니다.

---

## 2. 메인에서 「세팅 확인」보기

1. 메인 하단 **결투장 & 상급결투장 메타 덱** 카드에서 **세팅 확인**을 누릅니다.
2. 모달에서 **스킬 배치** / **디테일** 탭을 전환합니다.
   - 스킬 배치: 속공·스킬 순서
   - 디테일: 영웅별 장비·보석·장신구·조건 메모

> 메인 메타 덱은 **사이트 관리자가 올려 둔 공용 예시**입니다. 길드 전용 공략은 **길드 허브**에 있습니다.

---

## 3. 길드 허브 만들기

### 3.1 들어가기

1. 상단 **길드 허브** (또는 메인의 **길드 허브 입장하기**).
2. **구글 계정으로 로그인**합니다.
3. 계정당 **허브 하나**만 소속됩니다. 다른 길드로 가려면 먼저 나가기.
4. **60일 동안 활동이 없으면** 허브와 관련 데이터가 삭제될 수 있습니다.

### 3.2 허브 생성 (길드마스터)

1. **+ 허브 생성**을 누릅니다.
2. 입력합니다.
   - **길드 이름**
   - **길드 소속** (라운지 / 갤러리 / 아카 등)
   - **해시태그** (관심사·플레이 성향)
   - **마스터 닉네임** (보통 마이프로필 닉과 맞추면 됩니다)
3. **허브 개설**을 누릅니다.
4. 발급된 **초대 코드 / 초대 링크**를 길드원에게 공유합니다.

### 3.3 코드로 입장 (길드원)

1. **코드로 입장**을 누릅니다.
2. 초대 코드(`7K-XXXX-XXXX` 형식) 또는 초대 링크를 붙여 넣습니다.
3. 닉네임은 마이프로필에 저장된 이름이 사용됩니다.
4. 입장 후 허브 안에서 공략·공지·길드전 보드를 씁니다.

### 3.4 허브 안에서 자주 쓰는 것

- **공략 등록·수정** — 공성 / 강림 / 결투장 / 총력전 등 탭별 덱
- **세팅 확인** — 덱 카드에서 스킬·장비 상세
- **길드전** — 상대 덱·카운터 정리 (권한에 따라 편집)
- **초대 코드 복사 / 재발급** — 마스터·관리자
- **나가기** — 다시 들어오려면 초대 코드 필요

역할 요약:

| 역할 | 할 수 있는 일 (대략) |
|------|----------------------|
| 마스터 | 개설, 관리자 임명, 초대 재발급, 설정 |
| 관리자 | 공지·일부 관리, 강퇴(제한 있음) |
| 멤버 | 공략 작성·수정, 일반 이용 |

---

## 4. 공략 허브 (공용)

- 로그인·닉네임 후 **결투장 / 상급결투장 / 총력전** 등 **PvP 공략**을 올릴 수 있습니다.
- **PVE·티어리스트 편집** 등은 사이트 관리자 권한이 필요할 수 있습니다.
- 다른 사람 공략은 **세팅 확인**으로 동일하게 봅니다.
- **수정 및 고정자** 옆 시각은 **한국 시간(24시)** 기준입니다. 예: `(2026-08-23|15:34)`

---

## 5. 도감 · 도구

- **도감**: 영웅 / 장비·장신구 / 펫 / 시스템 규칙 확인
- **도구**: 길드전 승확 계산기, 티어리스트 메이커 등 (준비 중 표시가 있으면 아직 미개방)

---

## 6. 마이프로필

1. 우측 상단 **마이프로필**을 엽니다.
2. 닉네임(2~12자), 총력전·결투장 티어, 파괴점수, 아바타를 설정합니다.
3. 다른 유저 닉을 누르면 **공개 프로필**을 볼 수 있고, **사람마다 하루 1회** 추천할 수 있습니다. (같은 날 다른 사람은 가능 · 취소 불가)

---

## 7. 그 밖에 알아두면 좋은 것

- **입장 배너**: 관리자가 켠 공지가 뜨면 내용을 읽고 닫습니다. 「오늘 하루 안 보기」는 그 브라우저에만 적용됩니다.
- **오늘 방문자 / 전체**: 메인 히어로에 표시됩니다. 같은 브라우저는 하루에 한 번만 집계됩니다.
