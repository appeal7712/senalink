세나링크 이용 안내

세븐나이츠 유저용 길드 허브 · 공략 · 도감 · 도구
사이트: https://senalink.web.app

1. 상단 메뉴

메뉴하는 일
메인메타 덱·픽률·뉴스·입장 안내
길드 허브길드원끼리 공략·길드전·공지 (구글 로그인)
공략 허브공용 공략·티어리스트
도구승확 계산기, 티어리스트 메이커 등
도감영웅·장비·펫·시스템
마이프로필닉네임·티어·아바타 (우측 상단)
첫 방문 시 닉네임을 정해야 합니다. 닉네임은 마이프로필에서만 변경합니다.

2. 메인 「세팅 확인」

  1. 메타 덱 카드의 세팅 확인을 누릅니다.
  2. 스킬 배치 / 디테일 탭으로 속공·장비·조건을 확인합니다.
메인 메타 덱은 관리자가 올린 공용 예시입니다. 길드 전용 공략은 길드 허브에 있습니다.

3. 길드 허브

들어가기

  1. 상단 길드 허브 (또는 메인 버튼).
  2. 구글 로그인 — 계정당 허브 하나만 소속.
  3. 다른 길드로 가려면 먼저 나가기. 약 60일 무활동 시 데이터 삭제될 수 있음.

허브 생성 (마스터)

  1. + 허브 생성
  2. 길드 이름 · 소속 · 해시태그 · 마스터 닉네임 입력 후 허브 개설
  3. 초대 코드 / 링크를 길드원에게 공유

코드로 입장 (길드원)

  1. 코드로 입장
  2. 7K-XXXX-XXXX 또는 초대 링크 입력
  3. 닉네임은 마이프로필 저장값을 사용

4. 공략 허브

  • 닉네임 설정 후 PvP 공략을 올릴 수 있습니다.
  • 다른 공략은 세팅 확인으로 동일하게 봅니다.
  • 「수정 및 고정자」 시각은 한국 시간 24시 기준입니다.

5. 도감 · 도구 · 마이프로필

  • 도감 — 영웅 / 장비 / 펫 / 시스템
  • 도구 — 계산기·티어리스트 등 (준비 중 표시는 미개방)
  • 마이프로필 — 닉·티어·아바타. 공개 프로필에서 하루 1회 추천 가능(취소 불가)

6. 기타

  • 입장 배너 「오늘 하루 안 보기」는 그 브라우저에만 적용
  • 메인 방문자 수는 브라우저당 하루 1회 집계
